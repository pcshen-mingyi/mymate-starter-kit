# _raw —— 受保護資料夾

放**原始資料（raw data）**，例如系統匯出的原始檔、未清理的資料集。

設計原則：原始資料留在本機，不進入對話內容，也不送到外部。

## 保護是怎麼運作的

- **終端機啟動的 Claude Code**：自動攔阻（技術強制）。
- **Claude 桌面 App**：靠 Claude 遵守 CLAUDE.md 規則而拒絕存取，**無技術強制**。

若資料極度敏感，請放在這個資料夾**之外**、Claude 沒有存取權的位置。
詳見 `_private/README.md` 的說明。


## 保護強度

這個**資料夾**是最高強度——一律拒絕，使用者無法覆寫。
（相對地，只是「檔名看起來敏感」的檔案會改為詢問，讓你自己判斷。）
