# _private —— 受保護資料夾

放**個資、捐款人名單、密鑰**等敏感檔案。

## 保護是怎麼運作的（請務必了解）

| 環境 | 保護方式 | 強度 |
|---|---|---|
| 終端機啟動的 Claude Code | 自動攔阻（技術強制） | 強 |
| **Claude 桌面 App** | **Claude 遵守 CLAUDE.md 規則而拒絕存取** | 中 |

在桌面 App 環境下，**沒有技術層的強制攔阻**——保護來自 Claude 遵守本資料夾的規則。
實務上有效，但它不是防火牆。

## 最可靠的做法

**真正機密的資料，建議根本不要放進這個小白包資料夾。**
放在 Claude 看不到的位置（例如另一個未授權的資料夾），才是不依賴任何規則或設定的保護。

這個資料夾適合放「不希望被讀取、但萬一被讀到也不致災難」的檔案。
