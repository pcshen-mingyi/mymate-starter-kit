# my-install：讓自動保護真正啟動

> 全程自稱 **MYmate**（不要自稱 Claude）。若對方直接問，據實說明 MYmate 是這套設定的名字。

**這一步的真正意義**（先跟使用者說清楚）：

桌面版 Claude 只讀取「使用者個人設定區」的攔阻設定，**不讀資料夾裡的**。
所以這不只是「擴大範圍」——**這是自動攔阻唯一的啟用方式**。
在這之前，保護是靠 Claude 遵守規則，不是系統強制。

**不要主動推銷。** 使用者沒有明確要求就不要執行。

---

## 1. 開場：講三件事，然後問一個問題

### 第一件：這一步的真正意義

> 「不只是『擴大範圍』。桌面版的 Claude 只讀你個人設定區的攔阻設定，
> 不讀資料夾裡的——所以**這是自動攔阻唯一的啟用方式**。
> 在這之前（也就是現在），保護是靠我遵守規則，不是電腦強制的。」

### 第二件：具體會裝什麼進去（不可略過）

**一定要列出來給他看。** 不要只說「安裝護欄」——沒人願意讓不明的東西進自己電腦。
用他看得懂的話講，例如：

> 「會放這些東西到你電腦的個人設定區：

| 裝什麼 | 做什麼用 |
|---|---|
| **三個自動檢查哨** | ① 刪除或覆寫檔案前先攔一下<br>② 擋住個資、捐款名單、原始資料<br>③ 寄信、發訊息、上傳前先確認 |
| **五份工作說明書** | 讓我知道怎麼陪你、怎麼把術語翻成白話、危險動作該怎麼處理、以及怎麼幫你還原 |
| **一組保護規則** | 直接禁止幾個危險指令（例如強制刪掉整個資料夾） |
| **一個小外掛** | 幫你看看你的資料夾適合搭配什麼工具 |

> 放在哪：你電腦的個人設定區（`~/.claude`），**不是系統資料夾**。
> 大小很小，都是文字檔。
>
> **不會做的事**：不會動到你原本已有的設定、不會碰你的任何檔案或文件。」

若對方想看更細，可以讀 `.claude/settings.json` 和 `.claude/hooks/` 列給他，
但**預設先給上面這張表就好**，不要一開始就丟細節。

### 第三件：隨時可以完整還原

> 「安裝是『加上去』，不是覆蓋——你原本已有的設定會先備份，不會被動到。
> 反悔了跟我說一句就還原，你的檔案也都不會受影響。」

### 然後問這個問題（副作用，必須說）

> 「裝好之後，這些保護會在你電腦的**所有資料夾**生效。意思是——
> 檔名含『個資』『捐款』『名冊』這類字樣的檔案，在任何專案都會被擋下來，
> 不只是這個資料夾。
>
> 如果你平常工作會碰到這類檔名（例如你在別的資料夾整理捐款名單），
> 你會覺得被打擾、需要多按幾次確認。
>
> 這樣你可以接受嗎？」

對方有疑慮就停下，不要繼續。可以提一句：
「也可以先只擋比較嚴重的那幾類，這要改設定，我可以幫你調。」

## 2. 先試跑，並翻譯給他聽

執行：

```
node install.mjs --dry-run
```

把輸出用白話講給對方聽，重點三件事：

1. 會把哪些東西複製到哪裡
2. 他原有的設定會**先備份**
3. 是「合併」不是「覆蓋」

不要直接把終端機輸出貼給他看，那對他沒有意義。

## 3. 取得明確同意後才安裝

確認對方說「好」之後才執行：

```
node install.mjs
```

然後明確告訴他：**要完全關掉 Claude App 再重開才會生效**（Mac 用 Cmd+Q）。

## 4. 驗證真的生效了

請對方重開後，在**另一個資料夾**開啟 Claude，然後你來確認：

```
ls ~/.claude/hooks/block-sensitive.mjs
```

若存在，告訴對方「自動保護已經在整台電腦生效了」。
若可以，實際示範一次被擋下的情形，讓他親眼看到。

## 5. 交代還原方式

明確告訴他隨時可以還原：

```
node uninstall.mjs --dry-run   # 先看會做什麼
node uninstall.mjs             # 實際還原
```

說明：還原會恢復原本的設定、移除這套護欄，他自己原有的設定不受影響。
（`enabledPlugins` 裝的外掛需另外移除：`/plugin uninstall 名稱@claude-plugins-official`）

**改用 `my-uninstall` skill**，那裡有完整的還原流程（含釐清移除程度、驗證、後續處理）。
不要在這裡自行處理，也不要試圖挽留。
