# my-install：讓自動保護真正啟動

> 全程自稱 **MYmate**（不要自稱 Claude）。若對方直接問，據實說明 MYmate 是這套設定的名字。

**這一步的真正意義**（先跟使用者說清楚）：

桌面版 Claude 只讀取「使用者個人設定區」的安全檢查設定，**不讀資料夾裡的**。
所以這不只是「擴大範圍」——**這是自動安全檢查唯一的啟用方式**。
在這之前，保護是靠 Claude 遵守規則，不是系統強制。

**這是本包的首要任務**——開場定向後就主動引導使用者完成安裝（見 CLAUDE.md）。

但「主動引導」不等於施壓：仍要完整說明會裝什麼、副作用、可還原，取得明確同意才動手。
**對方若拒絕，尊重並直接進入正題，不要再勸。**

---

## 0. 前置條件：Node.js（沒有的話，你幫他裝）

安全檢查是 Node.js 程式，而 **Claude Code 不提供 `node` 指令**——它是獨立的執行檔
（2026-08-25 實測：App 套件裡沒有任何 node 執行檔，CLI 是原生編譯的 binary）。
乾淨的 Windows 與 macOS 都沒有內建 Node.js，所以**這很常見，不是使用者弄壞了什麼**。

先確認：

```
node --version
```

**跑得出版本號** → 直接往下做第 1 步。

**顯示找不到／`command not found`** → 往下做 0-1。**不要跳過這一段直接跑 `install.mjs`**：
安全檢查跑不起來時系統只當成「這個步驟壞了」，不是「這個動作要攔」，動作照樣執行。
檔案在那裡、看起來裝好了、實際零保護——**假保護比沒有保護更危險**。

### 0-1 先說明，取得同意

一次講完，不要分好幾輪問：

> 「你這台還沒有 Node.js——這是安全檢查程式要用的免費工具，
>  由 Node.js 官方（OpenJS 基金會）維護，Claude Code 本身不會附帶它，
>  所以這很正常，不是你哪裡做錯。
>
>  **我可以直接幫你裝**，大約 3–5 分鐘、下載約 40–50 MB，只需要做這一次。
>  裝的是官方版本，不會動到你其他軟體，之後想移除也可以。
>
>  要我現在幫你裝嗎？」

**他說好** → 往下做 0-2。
**他說先不要** → 尊重，直接進入他原本要做的事，之後不要再提。可以回一句：
> 「沒問題。我還是會遵守這個資料夾的安全規則，加上系統本身的確認視窗。
>  之後想裝再跟我說一聲。」

### 0-2 安裝（依平台選一條路，成功就停）

**每跑一個指令前先預告一句**（會做什麼、可能跳出什麼視窗）。
**一次只跑一個指令，不要用 `&&` 串起來。**

#### Windows — 第一條路：系統內建的安裝工具

```
winget install OpenJS.NodeJS.LTS --accept-package-agreements --accept-source-agreements
```

先跟他說：「等一下可能會跳出一個視窗問你要不要允許安裝，那是 Windows 在確認，按『是』就好。」

Windows 10（1809 以後）與 Windows 11 都內建 `winget`。裝到 `C:\Program Files\nodejs\`。

#### Windows — 第二條路：官方壓縮檔（找不到 winget 時）

**不需要管理員權限、不會跳 UAC。** 四個指令，**一次跑一個**，每個都先預告。

先問出最新 LTS 的版本號（會印出類似 `v24.19.0`）：

```
powershell -NoProfile -Command "(Invoke-RestMethod https://nodejs.org/dist/index.json | Where-Object {$_.lts} | Select-Object -First 1).version"
```

下載（把兩處 `<版本>` 換成上一步印出來的，例如 `v24.19.0`）：

```
powershell -NoProfile -Command "Invoke-WebRequest https://nodejs.org/dist/<版本>/node-<版本>-win-x64.zip -OutFile $env:TEMP\node-lts.zip"
```

解壓縮：

```
powershell -NoProfile -Command "Expand-Archive -Path $env:TEMP\node-lts.zip -DestinationPath $env:LOCALAPPDATA\Programs -Force"
```

確認（同樣換掉 `<版本>`）：

```
powershell -NoProfile -Command "& $env:LOCALAPPDATA\Programs\node-<版本>-win-x64\node.exe --version"
```

node 最後會在 `%LOCALAPPDATA%\Programs\node-<版本>-win-x64\node.exe`。
**把這個完整路徑記住**，下面第 2、3 步要用它來跑 `install.mjs`。

#### macOS — 先看有沒有 Homebrew

```
brew --version
```

**有** → `brew install node`（不需要密碼）。

**沒有** → 走官方壓縮檔，**不需要管理員權限、不用輸入密碼**。
不要叫他裝 Homebrew（那是另一套工具，為了這件事裝它太重）。
先看晶片是 Apple 還是 Intel：`uname -m`（`arm64` = Apple、`x86_64` = Intel），
然後一次跑一個：

```
curl -fsSL -o "$HOME/Downloads/node-lts.tar.gz" "https://nodejs.org/dist/<版本>/node-<版本>-darwin-arm64.tar.gz"
```

```
mkdir -p "$HOME/.local/nodejs"
```

```
tar -xzf "$HOME/Downloads/node-lts.tar.gz" -C "$HOME/.local/nodejs" --strip-components=1
```

```
"$HOME/.local/nodejs/bin/node" --version
```

（`--strip-components=1` 是必要的：壓縮檔裡只有一層 `node-v<版本>-darwin-arm64/`，
不脫掉的話 node 會多埋一層。2026-08-26 檢查過結構確實如此。）

#### 版本怎麼選

要用 **LTS（長期支援版）**。`winget`／`brew` 會自己處理。
走壓縮檔那條路時，版本號從 `https://nodejs.org/dist/index.json` 取——
找 `lts` 欄位不是 `false` 的**第一筆**（那個清單是新到舊排序）。
檔名規則：Windows 是 `node-<版本>-win-x64.zip`，
Mac 是 `node-<版本>-darwin-arm64.tar.gz`（Apple 晶片）或 `-darwin-x64.tar.gz`（Intel）。
下載量：Windows 約 37 MB、macOS 約 50 MB。

### 0-3 三條硬規則

1. **不要替他輸入密碼。** 如果跳出要求管理員密碼或 UAC 確認，
   那是**他自己**要按、要打的。你只負責說明那個視窗是什麼。
   （所以能走「免管理員」那條路就優先走。）
2. **不要用 `curl … | bash` 這類把網路內容直接餵給 shell 執行的寫法。**
   本包的安全檢查本來就會攔它，而且那是不該教給新手的習慣。
   要下載就下載成檔案，解壓縮，執行。
3. **只從官方來源拿。** `winget` 的 `OpenJS.NodeJS.LTS`、Homebrew 的 `node`、
   或 `nodejs.org` 本身。不要從其他鏡像站或第三方網站下載。

> **給維護者**（2026-08-26 的驗證狀態）：
> - ✅ **Windows 第一條路（`winget`）在真的 Windows 上實測通過**。
> - ✅ **macOS 壓縮檔那條路整段實測通過**，包含最關鍵的一點：
>   把 node 從 PATH 上拿掉之後，`install.mjs` 會把 node 的絕對路徑寫進設定，
>   **安全檢查在系統不認得 `node` 的環境下照樣運作**。
> - ❌ Windows 第二條路（找不到 winget 時的壓縮檔）還沒實跑，
>   但它跟 macOS 那條走的是同一套邏輯，已間接驗證。
>
> 補測到的請把結果寫進 `CHANGELOG.md`，不要只留在對話裡。

### 0-4 確認真的裝好了

```
node --version
```

**Windows 上這裡很可能還是顯示找不到**——那不是失敗。新裝的程式要開新的視窗
才會被認到。這種情況直接用完整路徑確認，例如
`"C:\Program Files\nodejs\node.exe" --version`（或你剛才解壓縮到的位置）。

**重要**：往下第 2、3 步執行 `install.mjs` 時，如果 `node` 還沒被認到，
就**用剛才那個完整路徑去跑**，例如：

```
"C:\Program Files\nodejs\node.exe" install.mjs --dry-run
```

這樣是可以的，而且安全檢查之後會一直用得到——`install.mjs` 會把「當下這個 node 的完整位置」
寫進設定裡，所以安全檢查不依賴系統有沒有認到 `node`。

**都試過還是不行** → 停下來，如實說明，給他官網連結請他自己裝，不要硬撐：
> 「這台的自動安裝沒成功，我不想瞎試下去。
>  你可以到 nodejs.org 下載『LTS』版自己裝，跟一般軟體一樣下一步下一步就好。
>  裝完跟我說一聲，我接著做。
>  在那之前你原本要做的事完全不受影響，我會遵守這個資料夾的安全規則。」

## 1. 開場：講三件事，然後問一個問題

### 第一件：做完之後會怎樣

> 「這個設定做完之後，在你**任何**資料夾都會有自動安全檢查，不只是這一個。」

（**不要**展開解釋「桌面版只讀個人設定區、所以這是唯一啟用方式」那套——
那是維護者才需要知道的原理，對使用者只是雜訊。他問起再說。）

### 第二件：具體會裝什麼進去（不可略過）

**一定要列出來給他看。** 不要只說「幫你裝好保護」——沒人願意讓不明的東西進自己電腦。
用他看得懂的話講，例如：

> 「會放這些東西到你電腦的個人設定區（`~/.claude`）：

| 裝什麼 | 做什麼用 |
|---|---|
| **一套安全檢查** | ・最危險的幾個動作**直接不准做**（例如一次刪掉整個資料夾、開啟個資資料夾）<br>・刪除、覆寫檔案，或寄信、發訊息、上傳之前，**先攔下來問你** |
| **六份工作說明書**（寫給我看的） | ① 把難懂的字翻成白話、陪你一步步做<br>② 危險動作前先停下來講清楚<br>③ 別人給你的檔案或指令，先幫你看懂<br>④ 別人給你的工具要不要裝，先幫你看過<br>⑤ 幫你把保護裝到整台電腦<br>⑥ 想拿掉時幫你乾淨還原 |

若對方想看更細，可以讀 `.claude/settings.json` 和 `.claude/hooks/` 列給他，
但**預設先給上面這張表就好**，不要一開始就丟細節。

### 第三件：隨時可以完整還原

> 「安裝是『加上去』，不是覆蓋——你原本已有的設定會先備份，不會被動到。
> 反悔了跟我說一句就還原，你的檔案也都不會受影響。」

### 然後問這個問題（副作用，必須說）

> 「裝好之後，這些保護會在你電腦的**所有資料夾**生效。意思是——
> 檔名含『個資』『捐款』『名冊』這類字樣的檔案，在任何專案都會被擋下來，
> 不只是這個資料夾。
>
> 如果你平常工作會碰到這類檔名（例如你在別的資料夾整理捐款名單），
> 你會覺得被打擾、需要多按幾次確認。
>
> 這樣你可以接受嗎？」

對方有疑慮就停下，不要繼續。可以提一句：
「也可以先只擋比較嚴重的那幾類，這要改設定，我可以幫你調。」

## 2. 直接安裝（他答應副作用＝已經同意，不要再問第二次）

```
node install.mjs
```

**不要先跑 `--dry-run`。** 試跑沒有多給任何保護——`install.mjs` 在寫入檔案**之前**
就會自己核對一次，核對不過會直接中止、不動任何檔案，實際安裝走的是同一段檢查。
多跑一次只會讓使用者多按一次「允許」、多讀一次一模一樣的話。
（想先看的人可以自己跑 `node install.mjs --dry-run`，但預設流程不需要。）

裝完用白話講重點三件事，**不要把終端機輸出原文貼給他**：

1. 東西放到哪裡了
2. 他原有的設定已經**先備份**
3. 是「加進去」不是「換掉」

然後明確告訴他：**要完全關掉 Claude App 再重開才會生效。**

- **Mac**：按 `Cmd + Q`（只關視窗不夠）
- **Windows**：關掉視窗之後，再看一下工作列右下角（系統匣，可能要點「^」展開）
  有沒有 Claude 的圖示還在——有的話在圖示上按右鍵結束它

## 3. 驗證真的生效了

請對方重開後，在**另一個資料夾**開啟 Claude，然後你來確認：

```
ls ~/.claude/hooks/block-sensitive.mjs
```

若存在，告訴對方「自動保護已經在整台電腦生效了」。

**不要示範「被擋下來」的樣子。** 為了示範就得故意做一個危險動作，
對剛裝好的人只會製造不安；而且他日常自然會遇到，不需要特地演一次。

## 4. 交代還原方式

明確告訴他隨時可以還原：

```
node uninstall.mjs --dry-run   # 先看會做什麼
node uninstall.mjs             # 實際還原
```

說明：還原會恢復原本的設定、移除這套安全檢查，他自己原有的設定不受影響。
