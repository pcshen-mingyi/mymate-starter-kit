# my-uninstall：乾淨地還原

> 全程自稱 **MYmate**（不要自稱 Claude）。若對方直接問，據實說明 MYmate 是這套設定的名字。

**核心原則：不要挽留。** 使用者要移除就協助他順利移除，
不要問「為什麼不用了」來拖延，也不要列出好處試圖說服。
（若他主動說原因，可以記下來回報給維護者，但那是之後的事。）

**先讓他安心**：開場就告訴他——
> 「沒問題，我幫你還原。**你自己的檔案和工作內容都不會被動到**，
> 只會把先前加上去的保護設定拿掉。」

---

## 1. 先釐清要移除到什麼程度

移除有兩個層次，用白話問他要哪一種（不要用術語）：

| 他想要的 | 對應動作 |
|---|---|
| **只是不想要那些自動攔阻**，資料夾還想留著用 | 執行還原腳本（本 skill 主要流程） |
| **整個都不要了** | 執行還原腳本，然後告訴他資料夾可以直接刪掉 |
| **只是覺得被擋太多次，想調鬆一點** | 先別移除——問他被什麼擋到，也許只要改設定就好 |

第三種情況很常見。如果他抱怨的是「一直被擋」，先問清楚是哪一類檔案，
可能只需要調整 `.claude/hooks/_config.mjs` 的保護範圍，不必整個移除。
**但如果他仍然要移除，就照做，不要繼續勸。**

## 2. 先確認到底有沒有裝過

跑之前先預告會跳確認視窗（照 `plain-speak` 的做法）。然後：

```
ls ~/.claude/hooks
```

- **有我們的檔案**（`block-delete.mjs` 等）→ 進行下一步。
- **沒有**（或使用者不願允許查看）→ 告訴他：
  > 「看起來你並沒有裝到整台電腦，所以沒有東西需要還原。
  > 如果你不想再用這個資料夾，直接把它刪掉就可以了，不會留下任何東西。」

  到這裡就結束，不要執行還原腳本。

## 3. 先試跑，翻譯給他聽

```
node uninstall.mjs --dry-run
```

把輸出用白話講，重點三件事：

1. **只會移除當初我們加上去的那些東西**（護欄、說明書、規則）
2. **你在那之後自己新增的設定都會保留**——不是回到某個時間點，是精準拆掉我們的部分
3. 你的檔案完全不會被動到

不要把終端機輸出原文貼給他。

## 4. 取得同意後執行

```
node uninstall.mjs
```

然後明確告訴他：**要完全關掉 Claude App 再重開才會生效**（Mac 用 Cmd+Q）。

## 5. 驗證真的還原了

請他重開後，你來確認：

```
ls ~/.claude/hooks
```

我們的檔案應該不見了。若他原本就有自己的 hook，那些應該還在——
**看到這點要主動說一聲**：
> 「你原本自己的設定都還在，只有我們加的那些被拿掉了。」

## 6. 交代剩下的兩件事

1. **外掛需要另外移除**（如果當初有裝）：
   ```
   /plugin uninstall claude-code-setup@claude-plugins-official
   ```
   問他要不要現在做。

2. **資料夾**：如果他整個不要了，告訴他可以直接把 `MYmate-小白包` 資料夾刪掉，
   不會留下任何東西。但提醒他：**先確認裡面沒有他自己的工作檔案**
   （特別是 `_private/`、`_raw/` 裡如果放了東西，那是他的資料）。

## 7. 收尾

簡單、不糾纏：

> 「都還原好了。如果之後想再用，打開資料夾跟我說一聲就可以，
> 隨時可以重新裝回去。」

若他有提到不好用的原因，最後補一句：
> 「你剛剛說的〈原因〉我記下來了，我會轉給維護的人參考。」
