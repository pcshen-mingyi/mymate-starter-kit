# MYmate 小白包 v0.1

給**第一次用 Claude Code** 的同事：下載這個資料夾、用 Claude Code 打開它，就可以開始用。
打開後會有一位叫 **MYmate** 的 AI 使用小幫手帶你完成前置準備。
需要的工具會自動裝好，也已內建安全保護。

支援 **macOS 與 Windows**，同一份資料夾兩邊通用。

## 📥 下載

**[點這裡下載小白包（zip）](https://github.com/pcshen-mingyi/mymate-starter-kit/releases/latest/download/MYmate-starter-kit.zip)**

不需要 GitHub 帳號、不需要登入。下載後解開壓縮檔，會得到一個 `MYmate-小白包` 資料夾——
用 Claude Code 打開它，在對話框輸入「幫我開始」就可以了。

> 解開後看到的檔案只有 `README.md`、`CLAUDE.md`、`install.mjs` 等幾個？
> 是正常的，設定都在隱藏的 `.claude/` 資料夾裡（見下方說明）。

## ⚠️ 先了解：自動保護需要「多一個步驟」才會啟動

實測結論（2026-08-05）：

| 狀態 | 自動攔阻 | 實際保護 |
|---|---|---|
| 剛下載、只打開資料夾（**多數人的起點**） | ❌ 還沒啟動 | Claude 遵守本資料夾規則 ＋ 系統確認視窗 |
| 做完「階段二」安裝之後 | ✅ 已啟動 | 技術強制攔阻 ＋ 上述兩者 |

原因：桌面版只讀取「你個人設定區」的攔阻設定，不讀資料夾裡的。
所以要讓自動保護真正生效，需要執行階段二（見下方，約一分鐘）。

**在那之前也不是沒有保護**——Claude 會遵守 `CLAUDE.md` 裡的安全規則（不讀 `_private`、`_raw`，
危險動作前先說明），加上系統本身的確認視窗。只是那是「規則」而非「技術強制」。

**無論如何請記住**：真正機密的資料，不要放進這個資料夾。
放在 Claude 看不到的位置，才是最可靠的保護。

## 設定分兩階段

| 階段 | 範圍 | 何時做 | 自動攔阻 |
|---|---|---|---|
| **階段一** | 只有這個資料夾 | 第一次使用，預設就是這個 | ❌ 尚未啟動 |
| **階段二** | 整台電腦任何資料夾 | 想啟用自動保護時 | ✅ 啟動 |

**先做階段一熟悉一下。** 階段一不會動到你電腦其他地方，隨時關掉資料夾就結束，沒有殘留。
想要真正的自動攔阻時再做階段二——它是自動保護唯一的啟用途徑。

---

## 階段一：在這個資料夾用（3 步）

1. **下載**（上方的下載連結）並解開壓縮檔，把資料夾放在你習慣的位置。
2. 用 **Claude Code 開啟這個資料夾**。
   第一次開啟時可能會跳出詢問是否信任 → 選「信任／允許」。
   （這只會問一次。）
3. 打聲招呼就好，例如「你好」。

我會先告訴你這裡能做什麼，然後帶你做一個**約一分鐘的設定**，
讓自動保護真正生效（隨時可以還原）。做完就可以開始用了。

不需要自己打任何安裝指令。

---

## 階段二：啟用自動保護（＋擴大到任何資料夾）

跟 Claude 說：**「我想啟用自動保護」** 或 **「我想在任何資料夾都能用」**
我會先讓你看清楚會做什麼，取得你同意後才動手。

**這一步的意義**：桌面版只讀你個人設定區的攔阻設定，所以這是讓自動保護
**真正生效**的唯一方式，不只是「擴大範圍」。

**先了解副作用**：啟用後護欄會在**所有資料夾**生效。
例如檔名含「個資、捐款、名冊」的檔案，在任何專案都會被擋。可接受再做。

也可以自己執行：

```bash
node install.mjs --dry-run   # 先看會做什麼
node install.mjs             # 實際安裝
```

安裝前會自動備份你原有的設定，不會覆蓋。

**隨時可以還原：**

```bash
node uninstall.mjs --dry-run   # 先看會做什麼
node uninstall.mjs             # 實際還原
```

會還原 settings、刪掉本包複製進去的 skill 與護欄，你自己原有的設定不受影響。
（plugin 需另外移除：`/plugin uninstall claude-code-setup@claude-plugins-official`）

## 這個包裡有什麼在幫你

| 名稱 | 它做什麼 |
|---|---|
| **plain-speak** | 遇到看不懂的字或畫面，翻成白話；過程中隨時告訴你進度 |
| **safety-check** | 刪除、寄出、動到敏感資料前，先攔一下並講清楚 |
| **explain-code** | 有人給你檔案或指令時，先幫你看懂它會做什麼、能不能跑 |
| **check-skill** | 想裝別人做的工具時，先幫你看那份指示會叫我做什麼 |
| **my-install** | 你想要更嚴格的自動保護時，幫你裝到整台電腦 |
| **my-uninstall** | 想拿掉的時候，乾淨還原（你的檔案不會被動到） |

你不需要記這些名字，直接說你想做什麼就好。

## 常見問題

**Q：跳出「要允許這個動作嗎？」我該怎麼辦？**
先看視窗裡的說明文字，它會用白話講這個動作會造成什麼。
不確定就選「拒絕」，然後直接問 Claude「這個動作會做什麼？」再決定。

**Q：設定會影響我電腦其他地方嗎？**
階段一不會，只在這個資料夾生效。只有你主動做了階段二，才會擴大到全機，而且隨時可還原。

**Q：哪些資料是受保護的？**
`_private/` 和 `_raw/` 兩個資料夾，以及檔名含密鑰、個資、捐款、名冊等字樣的檔案。
做階段二之前，這是靠 Claude 遵守規則而不去讀取（非技術強制）；做完階段二後才是技術強制。
極機密的資料請放在這個資料夾**之外**。

**Q：Windows 需要額外裝東西嗎？**
不用。安全保護與安裝腳本都用 Node.js 寫成，而 Claude Code 本身已包含 Node。

## 匿名計數（透明說明）

安裝與還原時，這個工具會回報**一筆匿名計數**，用來讓維護者知道有多少人在用、
判斷要不要進一步做訪談或問卷。

**會送出的，只有這三個：**

| 欄位 | 內容 |
|---|---|
| 事件 | `install` 或 `uninstall` |
| 版本 | 這個包的版本號 |
| 作業系統 | `darwin`（Mac）或 `win32`（Windows） |

**不會送出**：你的名字、機器識別碼、檔案名稱、檔案內容、資料夾路徑、對話內容——任何一項都沒有。
也**沒有任何識別碼**，所以無法追蹤個別使用者，也無法把你的安裝和還原配對起來。

（和所有網路請求一樣，伺服器端看得到你的 IP，但後端不記錄它——存下來的就只有上面那三欄。）

**不想回報**，設定這個環境變數即可：

```bash
export MYMATE_NO_STATS=1
```

其他說明：`--dry-run` 不會送出任何東西；回報失敗一律忽略，
**永遠不會影響安裝或還原本身**；程式碼在 `_stats.mjs`，歡迎自行查看。

## 給維護者

- 設計脈絡見《小白零思考上手 Claude Code：規劃與設計》（`02_產出/03_文件與框架/`）。
- 要調整護欄範圍：`.claude/hooks/_config.mjs` 的 `PROTECTED_DIRS`、`PROTECTED_FILE_PATTERNS`、`OUTBOUND_*`。
- 要調整預裝 plugin：`.claude/settings.json` 的 `enabledPlugins`。
- 版本紀錄見 `CHANGELOG.md`。
- 匿名計數**已啟用**（端點已部署並填入 `_stats.mjs`）；設定與關閉方式見 `docs/統計設定-給維護者.md`。
